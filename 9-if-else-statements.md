# IF ELSE Statements

### `if` STATEMENT

{% code overflow="wrap" %}
```python
age = 15

if age > 18:
    print("You can vote")

if age < 18:
    print("You cannot vote")
```
{% endcode %}



### `if else` STATEMENT

{% code overflow="wrap" %}
```python
age = 15

if age > 18:
   print("You can vote")
else:
   print("You cannot vote") 
```
{% endcode %}



### `if elif else` STATEMENT

{% code overflow="wrap" %}
```python
fruit = "apple"

if fruit == "banana":
    print("Banana is the fruit")
elif fruit == "mango":
    print("Mango is the fruit")
elif fruit == "pine apple":
    print("Pine Apple is the fruit")
elif fruit == "apple":
    print("Apple is the Fruit")
else:
    print("Fruit Not Found")
```
{% endcode %}
