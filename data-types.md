# Data Types

* Text
* Numberic
* Boolean



### Text

`str`: "Hello World", "John"

example:

{% code overflow="wrap" %}
```
message = "Hello World"
print(message)
```
{% endcode %}

### Numberic

`int`: -4,  0, 4

`float`: 3.045, 2.5

`complex`: 6 + 2i

example:

{% code overflow="wrap" %}
```
x = 25
print(x)
```
{% endcode %}

{% code overflow="wrap" %}
```
x = 2.576
print(x)
```
{% endcode %}

### Boolean

`bool`: True, False

example:

{% code overflow="wrap" %}
```
isSwitchOn = True
print(isSwitchOn)
```
{% endcode %}

{% code overflow="wrap" %}
```
isSwitchOn = False
print(isSwitchOn)
```
{% endcode %}





### How to Check its Data Type ?

{% code overflow="wrap" %}
```
x = 25
print(type(x))
```
{% endcode %}

outputs **int**
